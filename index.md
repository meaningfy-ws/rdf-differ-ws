## 🔎 What is it?
**rdf-differ-ws** is a web service for computing differences between RDF datasets.  
It highlights **added, removed, and modified triples** in a simple API, making it easier to track changes in knowledge graphs.

---

## 🚀 Quickstart

```bash
# Run with Docker
docker run -p 8080:8080 ghcr.io/your-org/rdf-differ-ws:latest
```
