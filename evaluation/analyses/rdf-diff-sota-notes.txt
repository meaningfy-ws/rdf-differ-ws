RDF Differ
- navigate to creation to upload files and enter some metadata
- navigate to listing to select profile/format and generate report
- refresh to download and view report

OWL Difference (Protege plug-in)
- compares any RDF vocabulary understood by Protege including OWL ontologies and their included imports
- failed to load reference OWL ontology for comparison due to unresolvable imports, so removed imports
- order matters (first open the latest one and compare against old/"original")
- can detect "refactor" operations with different strengths (ignore, conservative, reasonable, apply all algorithms)
- captures changes at the axiom level, meaning nearly all types of OWL changes including restrictions (presents Manchester-type of syntax for changes)
- runs in a few milliseconds
