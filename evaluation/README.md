# Evaluation

This folder contains some materials related to evaluating RDF Differ against other competing tools in the RDF/OWL diffing space, namely the OWL Difference Protégé plugin.

- **analyses** Any analysis or investigation artefact, including any worksheet/spreadsheet.

- **reports** Reports generated by one or more tools (currently just RDF Differ itself, as OWL Difference has no way to export or copy results).

- **screenshots** Snapshots of interesting points of the evaluation.

- **vocabularies** RDF vocabulary files used in the evaluation.
